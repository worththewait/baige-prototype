# 百舸数智平台原型

可离线分发的桌面交互原型，无构建步骤、无第三方运行时依赖。`index.html` 是完整平台入口，各业务界面仍由独立 HTML 维护。

## 打开与分享

完整下载或解压项目文件夹，双击 `index.html`，用现代桌面浏览器打开。无需安装依赖、启动服务或联网。请保留 `pages/`、`src/`、`assets/`、`styles.css`、`workspace.css`、`conversation.css` 的相对位置。

从 GitHub 下载：Code → Download ZIP，完整解压后再打开 HTML。单独发送 `index.html` 不包含其他页面和样式。

`pages/` 内页面也可单独打开，显示相应业务内容；需要侧栏和多个功能同时保留时，从 `index.html` 进入。

## 使用方式

- **新对话**：默认界面。居中欢迎语下方直接显示输入框，推荐问题收为紧凑入口；通用问答与知识问答共用输入框和对话区域。知识库说明位于输入区下方，不作为跳转入口。
- **知识问答**：点击输入区的模式按钮，按分类或名称搜索知识库，跨分类多选后确认；取消不会改变原有范围。输入草稿和已选范围在切换功能时保留。点击“新对话”保存已有会话并开始空白会话；初次发送后欢迎区收起，消息区展开，输入框位于底部。
- **历史会话**：对话页左上角开合历史栏，按日期分组、搜索会话名或问题内容。发送后自动记录会话，切换恢复消息、草稿和知识范围；没有发送过问题的空白会话不进入历史列表。历史保存在当前浏览器。
- **引用与原文**：从欢迎页下方或历史栏底部打开“引用与原文示例”，点击回答中的引用编号或参考资料卡片，在右侧定位示例段落。支持翻页、80%–150% 缩放、展开阅读和收起。隐藏后保留页码、缩放与阅读位置；顶部“原文”按钮可恢复预览。宽桌面可同时展示历史、对话和原文，较窄桌面自动腾出阅读空间。更换知识库不会修改已有回答的引用。
- **功能中心**：按“知识与研究 / 工具与平台”浏览，搜索覆盖所有分类。每个子功能独立一张卡片；可按工具用途筛选或仅看已开通。
- **知识库**：完整独立界面，统一浏览与搜索示例知识库，无侧栏下拉菜单。
- **工作区**：从功能中心进入的功能自动出现在侧栏。点击图钉固定，固定项排在前面；再次打开时只恢复固定项。取消固定不关闭当前页面。
- 多个功能使用独立页面实例；例如文档翻译、文本翻译可同时打开，通过侧栏切换，切换时不销毁原页面。工具表单只在本次打开期间保留，对话历史单独本地保存。
- Ctrl K / ⌘ K 打开功能中心并聚焦搜索。

固定项和对话历史存放于当前浏览器的 `localStorage`，不是账户云端同步。移动文件夹、更换浏览器、清理浏览器数据可能无法恢复；浏览器禁用存储时仍可使用当前工作区和本次会话，但无法跨次保存。附件内容不保存、不上传；恢复的附件仅有文件名，实际使用时需重新选择文件。

## 页面文件

```text
index.html                    统一入口、侧栏和工作区
pages/
  home.html                   新对话（同页通用问答 / 知识问答）
  center.html                 功能中心
  knowledge.html              知识库
  qa.html                     智能问数；兼容旧对话入口
  writing.html                百舸写作
  library.html                百舸文库
  intel.html                  百舸情报
  analysis.html               百舸分析
  tool.html                   单个智能工具页面，通过 hash 指定工具
  smart-tools.html            兼容旧智能工具地址，转入统一入口
  frontier.html               全球鹰 / 智研通
  digital.html                数智系统
  datasets.html               高质量数据集（列表、详情与申请弹窗）
  platform.html               智能开发平台
  data-platform.html          数据标注平台 / 爬虫平台 / 数据中台
```

功能中心共 27 项独立入口：知识与研究 7 项、工具与平台 20 项。12 项智能工具为文档翻译、文本翻译、OCR识别、纠错校对、提示词生成、专业编写、公文写作、PPT生成、文献伴读、思维导图生成、标准编制、专利编制。

## 代码维护

- `src/data.js`：原始分类、页面路径、工具说明、知识库示例与模拟权限。
- `src/catalog.js`：将原始分类转换为唯一的叶子功能目录。功能中心、侧栏工作区及路由共用该目录。
- `src/workspace-store.js`：当前打开项、本地固定项、存储异常与权限失效的处理。
- `src/app.js`：三个主入口、动态工作区、独立 iframe 与 hash 导航。
- `src/page-bridge.js`：父子页面通信、页面固定按钮和激活/离开/新对话事件。
- `src/pages/conversation.js`：问答模式、知识库选择器、历史列表、消息与引用交互。
- `src/conversation-store.js`：会话本地保存、草稿恢复、数据格式检查与存储失败降级。
- `src/conversation-data.js`：明确标注的示例对话、引用及本地演示原文；接入真实服务时替换为业务数据。
- `src/source-reader.js`：引用定位、独立原文预览、翻页、缩放、展开阅读与位置保留。
- `src/pages/center.js`：独立功能卡片、搜索、分类、已开通筛选及申请状态。
- `src/pages/knowledge.js`：知识库分类和搜索。
- `src/pages/tool.js`：单个工具标题、说明与集成占位；真实工具可在这里按工具名接入。
- `src/pages/datasets-data.js`：八个数据集的详情资料（核心价值、典型场景、服务模式与业务咨询），来自公开页面。
- `src/pages/datasets.js`：数据集列表与详情切换、页内 hash 跳转、申请弹窗校验与模拟提交。
- `src/home-access.js`：共享的模拟申请弹窗。
- `src/ui.js`：本地内联 SVG 图标与 HTML 转义。
- `styles.css`：基础组件与已有业务页面样式；`workspace.css`：当前工作空间样式；`conversation.css`：只在对话页加载的三栏布局、历史和原文阅读样式。

页面以普通 script 顺序加载，不使用 ES modules、fetch 或远程 CDN。父入口按“一级功能 + 子功能”的完整键保存 iframe；同一父目录下的两个功能不会共用同一个实例。postMessage 接收方校验已挂载窗口来源和页面标识，再校验目标功能。

`src/pages/landing.js`、`src/pages/home.js`、`src/pages/smart-tools.js`、`src/tool-workspace.js` 是旧版实现，当前主流程不加载。维护新交互时编辑上述当前脚本。

## 原型范围与权限

- 未接入能力显示“正在集成”。输入和示例消息仅用于界面演示，不发送到服务端，不进行翻译、模型推理、知识检索或文件上传。
- 知识库名称与介绍为示例。“引用与原文示例”是明确标注的本地演示内容，实际提交的问题不生成虚构回答或引用。高质量数据集页面复刻百舸门户公开介绍，正文、统计、八大核心数据集说明与各数据集详情均来自该页面，图片素材已保存到 `assets/` 与 `assets/datasets/` 以支持离线查看。
- 点击数据集卡片进入详情视图，页面 iframe 内的 hash 记为 `#dataset/<数据集名称>`（平台地址仍为 `#datasets`）；「返回数据集」回到列表并恢复原滚动位置。
- 详情末尾的「申请使用」打开申请弹窗：申请事由、使用范围多选、使用期限、申请人信息均为必填（使用范围至少一项）；提交只显示模拟成功状态，不发送到服务端。真实接入时可在页面脚本运行前提供 `window.BaigeRequestDatasetAccess(application)`。
- `permissions.routes` 控制一级功能，`permissions.children` 控制子功能，一级拒绝优先。未配置项默认允许。`permissions.libraries` 可按知识库 ID 配置访问权限。
- 当前“智能问数、智研通、标准编制”未开通，用于展示子权限差异。功能中心展示所有功能便于了解与申请；工作区只接受已开通项。
- 申请后本次页面内显示“待审批”，不会自动授权；刷新后模拟申请状态重置。
- 接入已有申请流程：在功能中心脚本运行前提供 `window.BaigeRequestAccess({ id, name, child? })`。回调只负责调用申请入口，不代表权限已授予。
- 前端模拟不是真实鉴权。真实接入时服务端仍需校验权限。
- 仅设计桌面版，完整平台最小宽度 1120px；无全局顶部栏。

