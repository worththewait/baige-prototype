# 百舸桌面工作空间设计

依据用户确认的两版草图与最后调整，直接实施于当前原型。

- 默认页面为新对话：通用问答与附加知识库问答共用同一输入区和消息流。右侧知识库问答区域仅作介绍，不可点击。
- 侧栏为新对话按钮、功能中心、知识库；下方工作区显示从功能中心打开的具体功能。点击图钉固定，下一次打开恢复固定入口；临时打开的入口只保留本次会话。
- 功能中心按知识与研究、工具与平台分组，27个叶子功能各一张紧凑卡片，无父子功能混装，无卡内翻页。
- 具体功能按权限显示进入、申请权限、待审批。申请模拟，不实际授权；工作区只出现有权限的入口。
- 知识库选择支持分类、搜索、多选、跨分类保留选择、取消和确认。零选择不可确认，只影响后续提问。知识库名称为明确标记的原型示例；实际内容未接入。
- 使用现有本地HTML、CSS与普通JavaScript，保留独立HTML与相对资源路径，整个目录双击index.html可用。桌面最小宽度1120px，不开发手机版。
- 视觉为浅灰侧栏、白色工作页、石墨灰文本与少量百舸蓝。系统字体离线可用。无全局顶部栏，不恢复通知、快捷工作路径、PA、知识工程。
- 保留已有业务页面与数据集内容。无内容的工具显示正在集成；不虚构问答结果、来源或联网能力。

设计取 editorial-greeting（seed 1235386681）的居中1100px内容列与色阶组织，采用已确认的问答/说明7:5布局替代无业务依据的统计块。品牌帆形标识与知识库选择范围构成产品识别。桌面断点检查1120、1440、1920，用户明确不需要移动端。
